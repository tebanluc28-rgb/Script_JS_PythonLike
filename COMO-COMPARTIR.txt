=====================================
 COMO COMPARTIR EL PROYECTO
=====================================

El paquete esta listo en la carpeta:
  AnimeBBG-Uploader-Pack/

Y tambien comprimido en:
  AnimeBBG-Uploader-Pack.tar.gz (65 KB)

=====================================
 METODO 1: Compartir la carpeta
=====================================

1. Comprime la carpeta "AnimeBBG-Uploader-Pack" en ZIP
   (Click derecho -> Enviar a -> Carpeta comprimida)

2. Comparte el archivo ZIP por:
   - Google Drive
   - Dropbox
   - WeTransfer
   - Correo (si es pequeño)

3. La otra persona debe:
   a) Descomprimir el ZIP
   b) Instalar Node.js desde https://nodejs.org/
   c) Ejecutar INSTALAR.bat
   d) Ejecutar INICIAR.bat
   e) Abrir http://localhost:3000 en su navegador

=====================================
 METODO 2: Usar el archivo .tar.gz
=====================================

1. Comparte el archivo:
   AnimeBBG-Uploader-Pack.tar.gz

2. La otra persona debe:
   a) Descomprimir con 7-Zip o WinRAR
   b) Seguir los pasos del METODO 1 desde el punto 3

=====================================
 LO QUE LA OTRA PERSONA NECESITA:
=====================================

OBLIGATORIO:
- Node.js 18 o superior
- Windows 10/11 (o Linux/Mac con adaptaciones)
- 500 MB de espacio libre

OPCIONAL:
- Cuenta en AnimeBBG (para usar el sistema)

=====================================
 NOTAS IMPORTANTES:
=====================================

❌ NO incluido en el paquete (se descarga automaticamente al instalar):
   - node_modules/ (se instala con npm install)
   - Chromium (se instala con playwright)

✅ El paquete es ligero (65 KB) porque no incluye dependencias

✅ Las dependencias se descargan automaticamente al ejecutar INSTALAR.bat

✅ El paquete NO incluye tus credenciales personales
   (la otra persona debe configurar las suyas)

=====================================
 SOPORTE:
=====================================

Si la otra persona tiene problemas:

1. Verificar que Node.js este instalado:
   node --version

2. Verificar que las dependencias esten instaladas:
   Debe existir la carpeta node_modules/

3. Revisar el archivo INSTRUCCIONES.txt

4. Si sigue sin funcionar, revisar los logs en la terminal

=====================================
 ACTUALIZACIONES:
=====================================

Si haces cambios al codigo y quieres compartir la version actualizada:

1. Ejecuta el script crear-paquete.bat nuevamente
2. Se creara un nuevo paquete con los cambios
3. Comparte el nuevo paquete
